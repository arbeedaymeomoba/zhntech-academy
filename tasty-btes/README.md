# TastyBite Restaurant Landing Page

Welcome to TastyBite, a modern and attractive restaurant landing page designed to showcase a delicious dining experience. This project presents a clean and responsive website layout for a food business, highlighting the restaurant’s specialties, popular dishes, testimonials, blog content, and contact information.

## Project Overview

TastyBite is a stylish landing page built with HTML and CSS to create an appealing first impression for visitors. It includes:

- A professional hero section with a welcoming introduction
- An About Us section describing the restaurant experience
- A featured dishes section for popular menu items
- Testimonials from satisfied customers
- A blog/news section for recent updates
- A modern footer with useful contact and social links

## Features

- Responsive and simple layout
- Attractive visual sections for food and dining
- Clear navigation menu
- Stylish call-to-action buttons
- Informative footer with contact details and social links

## Technologies Used

- HTML5
- CSS3

## Project Structure

- index.html – Main landing page structure
- style.css – Stylesheet for layout and design
- asset/images – Image assets used in the website

## How to Run

1. Open the project folder in your browser.
2. Double-click the index.html file, or use a live server extension in your code editor.
3. Explore the page and enjoy the design.

## Purpose

This project is ideal for learning how to build a professional restaurant or food website using basic front-end web development skills. It demonstrates how content sections, images, buttons, and footer information can be arranged to create a polished online presence.
